# 📈 매일 아침 국내/미국 증시 뉴스 카카오톡 자동 발송기

별도의 유료 API나 외부 패키지(`pip install`) 없이 **파이썬 기본 내장 라이브러리**만으로 **구글 뉴스 RSS(한국어)**에서 간밤 **미국 증시**와 **국내 증시 시황** 주요 뉴스를 수집하여, 매일 아침 **카카오톡 '나에게 보내기'**로 전송하는 GitHub Actions 프로젝트입니다.

> **보안 원칙**: 카카오 API 키와 토큰은 이 폴더의 파일이나 노트에 저장하지 않고, GitHub 저장소의 `Actions Secrets`에만 등록해 사용합니다.

---

## 📁 파일 구성

- `1_get_token.bat`: **(더블클릭용)** 최초 1회 카카오 로그인으로 토큰을 발급받고 즉시 내 카톡으로 테스트 뉴스를 보내보는 실행 파일
- `2_test_news.bat`: **(더블클릭용)** 카카오 연결 전, 어떤 뉴스가 수집되는지 화면에서 미리 확인하는 실행 파일
- `send_stock_news.py`: 미국 증시 / 국내 증시 시황 뉴스 각 3건을 수집해 카카오톡 나에게 보내기로 발송하는 메인 코드
- `get_kakao_token.py`: `1_get_token.bat`이 실행하는 토큰 자동 발급 도우미 코드
- `.github/workflows/daily_stock_news.yml`: 평일 아침 07:30(한국 시간)마다 GitHub 서버에서 자동 실행되는 스케줄 설정 파일

## 🚀 처음부터 끝까지 따라 하기 (카카오 개발자 센터 최신 개편 화면 기준)

### 1단계: 카카오 개발자 사이트에서 스위치 4개 설정하기 (약 3분)

최근 카카오 디벨로퍼스 화면이 개편되어, 왼쪽 메뉴가 **`[앱]`**과 **`[카카오 로그인]`** 구조로 바뀌었습니다. 아래 순서대로 진행해 주세요!

#### ① 카카오 로그인 먼저 켜기
1. 왼쪽 메뉴에서 **[카카오 로그인] > [일반]**을 클릭합니다.
2. 맨 위 **활성화 설정** 옆의 상태를 클릭해 **`ON` (활성화)**으로 바꿉니다.

#### ② REST API 키 안에서 Redirect URI 등록하기
1. 왼쪽 메뉴 맨 위 **[앱] > [플랫폼 키]**를 클릭합니다.
2. 화면에 보이는 키 목록 중에서 **`REST API 키`** 항목을 클릭해서 상세 설정 화면으로 들어갑니다.
   - *(여기 있는 32자리 영어+숫자가 본인의 **REST API 키**입니다.)*
3. 상세 화면 아래쪽에 있는 **`카카오 로그인 리다이렉트 URI` (Redirect URI)** 항목에서 **[등록]**(또는 수정) 버튼을 누릅니다.
4. 입력 칸에 아래 주소를 그대로 붙여넣고 **[저장]**을 누릅니다:
   ```text
   http://localhost:5000/oauth
   ```

#### ③ 카톡 메시지 버튼 링크용 웹 도메인 등록하기
1. 왼쪽 메뉴 **[앱] > [제품 링크 관리]**를 클릭합니다.
2. **`웹 도메인`** 항목에서 **[도메인 등록]** 버튼을 클릭합니다.
3. 입력 칸에 카톡 하단 '뉴스 더보기' 버튼이 이동할 주소인 아래 도메인을 넣고 **[저장]**을 누릅니다:
   ```text
   https://finance.naver.com
   ```

#### ④ 카카오톡 메시지 전송 동의항목 켜기
1. 왼쪽 메뉴 **[카카오 로그인] > [동의항목]**을 클릭합니다.
2. 화면을 맨 아래로 쭉 내리면 **접근권한** 표 안에 **`카카오톡 메시지 전송 (talk_message)`** 항목이 있습니다.
3. 우측 **[설정]** 버튼을 누르고 → **[선택 동의]** 선택 → 동의 목적 칸에 `개인 뉴스 알림`이라고 적고 **[저장]**을 누릅니다.

### 2단계: 내 휴대폰으로 첫 카톡 받아보기 & 토큰 발급 (1분)

1. 탐색기에서 `D:\SecondBrain\40_Personal\Finance\Kakao-Stock-News` 폴더 안의 **`1_get_token.bat`** 파일을 **더블클릭**합니다.
2. 검은 창이 뜨고 `1단계: 카카오 앱의 [REST API 키]를 붙여넣고 Enter를 누르세요:` 라고 나오면, **REST API 키**를 붙여넣고 **Enter**를 누릅니다.
3. `2단계: Client Secret...` 질문이 나오면 아무것도 입력하지 말고 그냥 **Enter**를 한 번 더 누릅니다.
4. 자동으로 인터넷 브라우저가 열리면서 노란색 카카오 동의 화면이 뜹니다.
   - **[전체 동의하기]**에 체크하고 **[동의하고 계속하기]** 버튼을 누릅니다.
5. 누르는 즉시 내 휴대폰 카카오톡(나와의 채팅방)으로 뉴스 2통이 도착하고, 검은 창에 `KAKAO_REST_API_KEY`와 `KAKAO_REFRESH_TOKEN`이 출력됩니다!
